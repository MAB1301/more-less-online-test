# Game Night
Original instrumental loop generated by scripts/build-game-music.py. 96 BPM, soft synthesizer chords, bass and arpeggio; 20 seconds, no vocals or external samples. Released under CC0-1.0. Background music starts only after the player explicitly enables it. Files supplied later can replace or extend the track list in assets/comfort.js.


Shop collection (2026-10-05), generated by `scripts/build-shop-music.py` from oscillators and synthesized drums:

- Night Drive: 124 BPM, 16-bar house loop, 30.97 s.
- Pixel Riot: 144 BPM, 16-bar breakbeat/chiptune loop, 26.67 s.
- Moon Bounce: 108 BPM, 16-bar offbeat FM/glitch loop, 35.56 s.

All three are original instrumental compositions without external samples, existing recordings, lyrics or deliberately copied melodies. The included code and recordings are dedicated under CC0-1.0. Deterministic seeds and source are kept for provenance. The shop unlock is a game feature; these static files are public assets, not DRM. Later commercial songs must be separately licensed for the actual game/web use, recording, territory and distribution; a personal streaming subscription or a virtual coin purchase does not supply those rights.
