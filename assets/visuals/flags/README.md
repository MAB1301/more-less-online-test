# Lokale Länderflaggen

SVG-Dateien von `https://flagcdn.com/<code>.svg`, am 5. Oktober 2026 für die
Offline-App übernommen. Flagcdn stellt die Flaggen des Flagpedia-Projekts
bereit: https://flagpedia.net/download/api. Die Codes entsprechen COUNTRY_CODE
im Spiel. Die installierte App verwendet diese Dateien statt externer Bildaufrufe.
