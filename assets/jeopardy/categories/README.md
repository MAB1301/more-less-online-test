# Jeopardy category imagery

26 installed original AI-generated category illustrations in a realistic photographic style, created on 2026-10-04 for Game Night. These are decorative depictions, not documentary photographs or official imagery. Transfer, trophy and FIFA-rating pictures do not assert a real transfer, official badge, rating or product appearance.

Each category has its own WebP image. Board headers and question backgrounds share the same mapping in `../categories.js`. Images have empty alternative text because the adjacent visible category title provides the information. Text stays on dark surfaces. Generation subjects and sources are recorded in `sources.json`.
