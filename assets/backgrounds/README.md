# Game backgrounds

Four user-approved original decorative AI-generated backgrounds, created with the built-in image generation tool on 2026-10-04. Menu: cinematic games lounge. Jeopardy: realistic blue quiz studio. Estimate: precision measurement workbench. Facts: glass check/cross studio. Each prompt required dark calm central space and photorealistic materials with restrained navy, blue and violet lighting. These are decorative concept depictions, not official game artwork. Optimized WebP versions preserve the approved full composition.

Normal mode uses these assets in the main menu and corresponding game menus/play surfaces. More/Less keeps its existing background. Data-saving mode substitutes CSS gradients, prevents new category-header requests and removes large decorative backdrops. Relevant question illustrations remain available. Stored data-saving preference is applied before styles load; a browser Save-Data preference is honored until manually overridden. Previously downloaded bytes cannot be recovered by switching modes.

Live HTML controls, larger cards, tighter spacing and CSS LED text are separate from the image. No changes to game-specific backgrounds.
