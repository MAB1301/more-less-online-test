# Fakten zuordnen – Dark & Freisteller

The 4-column, 3-row animal atlas contains generated photorealistic illustrations,
not source photographs. Created with the built-in image generation tool on
2026-10-09, converted to WebP without changing pixel dimensions or transparency.

Row 1: tiger, polar bear, snow leopard, giant panda.
Row 2: elephant, giraffe, lion, cheetah.
Row 3: mallard, wood duck, bald eagle, American robin.

Prompt: twelve isolated naturalistic animal bust portraits in equal 4x3 cells,
transparent background, mature dark game card style, subtle cool rim light,
no labels, no numbers, no scenery. CSS displays one equal atlas cell per name.

Other name cards reuse local catalogue illustrations. Entries marked `category`
use a generic category motif rather than claiming an image of that subject.
Fact cards do not carry subject imagery or group-specific colours. All selections
use the same cyan outline. Existing factual values and rules are unchanged.
