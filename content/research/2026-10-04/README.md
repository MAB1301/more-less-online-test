# Release: content, Jeopardy and game comfort

This release adds 135 playable More/Less comparisons across every one of the fourteen existing categories, 85 estimates, 54 balanced Fact/Fake statements, and 294 reviewed Jeopardy clues. The approved pack totals 691 comparisons, 213 estimates, 114 statements and 354 clues, plus the existing built-in banks. All twelve original Jeopardy categories now contain at least twenty clues; twenty-six categories are playable overall.

`build-expansion-5.py` and `build-expansion-6.py` regenerate authored content; their JSON manifests preserve sources and cutoffs. FC26 and FC27 are separate editions. Football claims identify the transfer year or career cutoff and distinguish a loan from a permanent transfer. Planetary values distinguish mass, density, escape velocity, equatorial acceleration and gas-planet reference levels. Three new standard boards were tested to contain ninety different clues. Online boards share a match-specific signal, preserving reconnects while changing rematches.

The additional numbers include phone country codes (ITU), city area (municipal authorities/election statistics), construction starts (operators), national-park areas (NPS), birth-weight ranges (San Diego Zoo), relative atomic masses (RSC), adult regulation playing time (IFAB/FIBA/IHF), combustion-engine torque/displacement/rev limits (manufacturers), UNESCO property areas, card colours, launch masses (NASA/ESA), and calculated record-run mean speeds. For the latter, distance divided by the dated published time is explicitly described as a calculation. Ranges, rounded values, source-year differences, launch adapters and UNESCO buffer zones are identified in the catalogue notes. Belgian area is explicitly the Statbel 2023 snapshot; the 2025 rounded value differs.

Numeric questions are generated only between the same category, metric and unit. Equal answers are excluded. New sources were reviewed against primary publishers; a bulk accessibility check of the previous catalogue obtained 82 of 88 URLs. Six inaccessible responses were not treated as factual contradictions. Historical edition figures and dated records are retained rather than replaced by a current page without accounting for its edition.

The additive SQL import contains 274 shared-online/Daily candidates (135 More/Less, 85 estimate, 54 facts). It does not rewrite started matches or already generated Daily sets. New Jeopardy clues are loaded by the client content pack. The full-match SQL fixture tests ten-question estimate and new-content Fact/Fake games, private answers, host absence, host takeover, reconnect and final scores, and rolls back all fixtures.

Jeopardy uses the page's violet/cyan palette, bounded question overlays and a two-page, three-column mobile board. Three independent interactive visual proposals are available in `qa/jeopardy-designs.html`. The current game keeps its existing scoring and online state. The comfort dialog adds opt-in original music, independent effect/music volume, reduced motion, larger text and higher contrast. Music never starts by default; muting and backgrounding pause it. The original CC0 loop and reproducible synthesizer are included.

Validation: full static/VM regression suite; full-page JSDOM interaction check including settings focus and mobile category paging; server transaction fixtures. Responsive browser checks simulate sizes. Physical iPhone/iPad Safari, on-screen keyboards and separate physical-device network tests require actual hardware. Supabase leaked-password protection remains unavailable to this run: the dashboard requires sign-in and the feature requires Pro or higher. Neither physical verification nor enabling that setting is claimed.
